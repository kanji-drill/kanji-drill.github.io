# 漢字ドリル 運用手順書

講師（あなた）が行うことと、Claude に頼むことをまとめています。GitHub の操作は Claude が担当します。

## あなたが行うこと

### 1. 最初だけ：GitHub アカウントを作る
1. https://github.com/signup でアカウントを作る（無料プランで足ります）。
2. 作ったら、Claude に「GitHub アカウントを作った。ユーザー名は ○○」と伝える。
   - リポジトリの作成、アップロード、GitHub Pages の公開設定は Claude が行います（その都度あなたに確認します）。
   - Claude が GitHub を操作するには、最初の 1 回だけ、Claude からの案内に沿って `gh auth login` でのログインが必要です。
   - リポジトリは、個人のユーザー名が URL に出ないよう、組織 `kanji-drill` に置いています（リポジトリ名 `kanji-drill.github.io`、公開 URL は https://kanji-drill.github.io/ ）。組織の管理者は、あなたの個人アカウントです。

### 2. 問題（語彙マスタ）の確認
1. Claude に「確認用の一覧を出して」と頼むと、`review.html` が作られます。ブラウザで開いて読みます。
2. 誤りを見つけたら、**番号と直し方**をそのまま Claude に伝えます。
   - 例：「w0012 の例文が不自然。『〜』にしたい」「w0045 の読みが違う」
3. 問題がない音のグループは「○○（音）のグループは確認済み」と伝えます。Claude が確認済みの印を付けます。
4. 確認の観点
   - 語と読みが正しいか
   - 例文の文脈で、その漢字の語に決まるか（同じ音の別の語と取り違えないか）
   - 常用漢字の字体か（例：「𠮟」「剝」「頰」「塡」は常用漢字表の字体に統一しています）

> 生徒に出題するのは、確認済みの語だけです。確認前の語は、公開しても出題されません。試作運用の間は、アプリの上部に「試作版」と表示されます。試作運用が終わったら、Claude に「本番版に切り替えて」と伝えてください（表示が消えます）。

### 3. 生徒への配布
公開後に Claude が知らせる URL を、生徒に送ります。配布文の例：

```
漢字ドリル（共通テスト型）の URL です。
https://kanji-drill.github.io/

・ノートとペンを用意して、スマホを立てて使います。
・1 問ずつ、番号と全部の選択肢の漢字をノートに書いてください。
・答え合わせで、書けなかった語に✕を付けると、間隔をあけて復習に出てきます。
・最初の 1 セットが終わったら「ホーム画面に追加」してください（iPhone は Safari の共有ボタン→「ホーム画面に追加」）。
・記録はスマホの中だけに保存されます。機種変更の前に、設定の「記録を書き出す」で保存してください。
```

### 4. 試作運用（3〜5 人・2 週間）
- 生徒に、結果画面のスクリーンショット（または書き出したファイル）を送ってもらいます。
- 2 週間後、次の 3 つで判定します。
  1. 半数以上の生徒が、10 日のうち 7 日以上使った
  2. 1 セットにかかる時間の中央値が 15 分以下
  3. 重複や誤った問題の報告が 0 件
- 結果を Claude に伝えると、1 セットの問題数・1 日の上限・復習の間隔を調整します。

## 生徒から「機種変更する」と言われたら
1. 古いスマホで：設定 → 「記録を書き出す」→ できたファイルを新しいスマホに送る（メールや AirDrop など）
2. 新しいスマホで：アプリを開く → 設定 → 「書き出したファイルを読み込む」→ 「上書きする」

## Claude に頼むこと（例）
| したいこと | 伝え方の例 |
|---|---|
| 問題の誤りを直す | 「w0012 の例文を『〜』に直して公開して」 |
| 語を増やす | 「過去問の語を送るので、マスタに足して」（写真や PDF でも可） |
| 確認済みにする | 「コウとショウのグループは確認済み」 |
| 本番版に切り替える | 「全部確認したので本番版に切り替えて」 |
| 分量を変える | 「1 日の新しい問題を 2 セットまでにして」 |

## 開発者向けメモ（Claude が使う）

| コマンド | 内容 |
|---|---|
| `npm run dev` | フォントを作ってから開発サーバーを起動 |
| `npm test` | 単体テスト（出題・復習・マスタの検査・周回の模擬） |
| `npm run validate` | 語彙マスタの検査 |
| `npm run simulate` | 周回の模擬（使用済みの語で埋める割合が 10% 以下か） |
| `npm run review` | 確認用一覧 `review.html` を生成 |
| `npm run build:pilot` | 試作運用のビルド（「試作版」と表示。出題は確認済みの語だけ） |
| `npm run build` | 本番ビルド（確認済みの語だけ） |
| `npm run e2e` | 試作ビルドを作って Playwright で E2E テスト |
| `npm run lint` | Biome |
| `npx tsx tools/make-icons.ts` | アイコンを変えたときに PNG を作り直す |

- 画面の文言を変えたら `npm run fonts` を実行する（使う字だけをフォントに含めているため）。`build` と `dev` では自動で実行される。
- 語を足すときは、同音グループを「1 漢字 2 語・漢字 3 の倍数種（6・9・12…）」の形に揃える（D25）。1 問は同じ漢字の 2 語と別の漢字 4 語を使うため、この形だと周回でちょうど使い切れる（崩すと `npm run simulate` の割合が上がる。実測：形を揃える前 15.8% → 揃えた後 7.5%）。音読みの常用漢字が 5 種しかない音（チク、バクなど）は、例外として 3,3,2,2,2 の形にする。
- 出題プログラムは、誤りの選択肢に「未使用の語が 2 つ残る漢字」を使いすぎないようにしている（その漢字は後の問題の正解の組に要るため）。これがないと漢字 9 種以上のグループで周回の最後の問題が組めず、埋め合わせが増える（2026-10-16 修正。582 語で 11.8% → 3.0%）。
- 過去問から集めた語は `private/past-exams.csv`（公開リポジトリには入れない）。マスタでは `tier: "past"` と `source` に出典を入れている。
- 2000〜2023 年度の分は、ユーザーが用意した PDF（`private/pdfs/`）から読み取った。読み取り結果の元データは `private/center-transcribed.txt`（1 行 = 1 問）。スキャン PDF は画像を目視で、文字情報のある PDF はテキスト抽出で読んだ。正解の番号は問題の内容から判断したもので、解答 PDF とは照合していない。
- マスタの構成は「過去問の語ができるだけ多くなるように、同音グループ（1 漢字 2 語・漢字 3 の倍数種）を選ぶ」方針。D25 で常用漢字全体（漢検 2 級まで）に広げる。出題できる字・できない字の集計は `private/joyo/coverage.md`（Wikipedia「常用漢字一覧」から作成。非公開）。語の下書きは `private/batchN.tsv` に書き、words.json に `verified: false` で足す。
- 訓読みの語は `kun: true` とし、`word` は「漢字 1 字＋送り仮名」（例：競う）、`kana` は漢字部分のカタカナだけ（例：キソ）、`reading` はその漢字の音読み（例：キョウ）にする。例文は `速さを{キソ}う` のように、{} の直後に送り仮名を続ける（活用してよい）。`npm run validate` がこの形を検査する。
- 別の正しい表記がある語は `alt` に入れる（例：換える の `alt: ["替える"]`）。答え合わせ・結果・確認用一覧でカッコ書きされ、どちらを書いても正解として扱う。意味で書き分ける語（省みる／顧みる）は `alt` にせず、別々の語として登録する。
- 新しく入れた語を先頭にまとめた確認用一覧は `npx tsx tools/build-review.ts --since w0642` で作る（番号は今回追加した語の最初の番号。第 1 弾は w0642〜w0827）。
- 語の `id` は一度振ったら変えない。語を消すときは、生徒の記録との対応を壊さないよう、消す前に方針を決める（v2 で `retired` を導入予定）。
- 公開は `.github/workflows/deploy.yml`。`main` に push すると、テスト → 試作ビルド → GitHub Pages の順に自動で動く。本番版に切り替えるときは、`build:pilot` を `build` に変える。確認前の語は、どちらのビルドでも出題しない（`npm run dev` では出す。公開ビルドで出したいときだけ `VITE_INCLUDE_UNVERIFIED=1` を付ける）。
